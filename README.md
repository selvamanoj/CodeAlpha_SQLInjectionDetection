# SQL Injection Detection System

## About the Project
The SQL Injection Detection System is a web application designed to detect possible SQL injection attacks in user inputs. It helps improve application security by identifying suspicious input patterns.

## Features
- Detect suspicious SQL injection patterns
- Analyze user input
- Display detection results
- Simple and user-friendly interface

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## Project Objective
The main objective of this project is to understand SQL injection attacks and develop a basic system to detect potentially harmful inputs.
